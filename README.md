# Student Grade Calculator

Учебное веб-приложение для демонстрации PaaS: пользователь вводит ФИО и три оценки (две контрольные и экзамен), приложение считает средний балл и выводит PASS (ЗАЧЁТ) при среднем ≥ 50.

Стек: Python + Flask, запуск через gunicorn.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/nowomann0cry/student-grade-calculator)

Локальный запуск:
```
pip install -r requirements.txt
python main.py   # http://localhost:8080
```
